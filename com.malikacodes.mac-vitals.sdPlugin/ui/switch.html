The Wi-Fi switch. It shows which network the Mac is on, and a press moves to the next one in the list below.
 For a long name, add what the key should say: My Very Long Network Name = Home
  • Lit symbol and a lit dot: the Mac is on that network
  • Name with a gray symbol: on its way there, give it a few seconds
  • Other Wi-Fi: on a network that isn't in my list
  • No Wi-Fi or Wi-Fi off: not connected to anything
  • No password: that network's password isn't saved for this key yet. It's saved once from Terminal, the README has the command
  • Can't join: the saved password is wrong, or the network is out of range
  • The menu bar can lag a few seconds behind after a press. The key is the one to trust
